## 🎂 Descripción del Proyecto

El proyecto tiene como objetivo modernizar la venta y difusión de repostería 100% tradicional chilena, facilitando que las familias disfruten de la tradicional **once chilena** o celebren momentos especiales.

### Características Principales:
1. **Catálogo Interactivo con Precios ($ CLP):**
   * **Tortas Tradicionales:** Milhojas Manjar Nuez ($28.000), Selva Negra ($26.500), Tres Leches ($25.500), Panqueque Trufa ($27.500) y Personalizadas ($35.000).
   * **Cupcakes y Minipasteles:** Caja Surtida x6 ($10.500), Red Velvet x12 ($19.000) y Cheesecakes individuales ($3.800).
   * **Línea Inclusiva y Saludable:** Torta Vegana Choco-Frambuesa ($29.900), Torta Sin Azúcar Frutos Rojos ($31.000) y postres Sin Gluten Certificados para personas celíacas ($4.500).
2. **Esquema de Seguridad & Registro de Clientes:**
   * Formulario con validación de **RUT Chileno** (Módulo 11), contraseña con medidor de fuerza, dirección y comuna.
3. **Cobertura y Delivery San Bernardo:**
   * Mapa oficial de cobertura para San Bernardo y proyección para comunas de la RM.
   * Verificador interactivo de despacho y tarifa gratuita sobre $30.000.
4. **Carrito de Compras y Pedidos:**
   * Carrito desplegable con cálculo en tiempo real, soporte de cupones de descuento y confirmación con resumen directo a WhatsApp.
5. **Contador de Visitas en Vivo:**
   * Contador persistente y animado para el registro de visualizaciones de la publicación web.

## 🚀 Cómo Visualizar el Proyecto

1. Clona o descarga este repositorio:

2. Abre el archivo `index.html` en cualquier navegador web moderno (Google Chrome, Edge, Safari, Firefox).
